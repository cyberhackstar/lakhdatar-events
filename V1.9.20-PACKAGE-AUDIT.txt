LAKHDATAR EVENTS v1.9.20 PACKAGE AUDIT
======================================
Release: 1.9.20
Purpose: Correct the false production deployment failure caused by localhost smoke-test Host headers while retaining the v1.9.19 NGINX edge startup fix.

PRIMARY FIXES
-------------
1. Production deploy smoke tests now send Host: events.neelastack.com and X-Forwarded-Proto: https when testing the loopback edge at 127.0.0.1:4002.
2. Smoke failures now report the URL, Host, HTTP status, response headers and a bounded response body.
3. Angular SSR production runtime explicitly receives NG_ALLOWED_HOSTS=events.neelastack.com and NG_TRUST_PROXY_HEADERS for the X-Forwarded-* headers controlled by the NGINX edge.
4. CI's direct Angular SSR smoke test uses an explicit test-only host allowlist and trusted-proxy setting.
5. The v1.9.19 NGINX duplicate-PID/startup validation remains unchanged and is covered by the baseline validator.
6. First-production VM preflight/cleanup guidance is included and is scoped to Lakhdatar resources only.

VM SAFETY
---------
Never run broad 'docker system prune -a', 'docker image prune -a', or 'docker volume prune' on the shared Oracle VM.
The production stack is isolated by fixed Compose project/network/container/volume names and uses only host port 127.0.0.1:4002.
Do not remove PostgreSQL or Redis volumes as part of this release.
