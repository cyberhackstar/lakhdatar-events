LAKHDATAR EVENTS v1.9.22 FINAL ENTERPRISE RELEASE MANIFEST
=========================================================
Release: 1.9.22
Base: v1.9.19 edge-startup corrective release.
Primary correction: fixes the production deployment smoke-test contract so local origin checks emulate the canonical public Host and HTTPS proxy scheme instead of sending Host: 127.0.0.1, which Angular SSR correctly rejects with HTTP 400 under its host/SSRF protection.
Frontend SSR hardening: explicitly configures NG_ALLOWED_HOSTS and NG_TRUST_PROXY_HEADERS for the trusted NGINX edge; production accepts only events.neelastack.com while CI localhost SSR tests use an explicit test-only allowlist.
Smoke-test diagnostics: failed endpoints now report the exact URL, Host, HTTP status, response headers and a bounded response body instead of exposing only curl exit code 22.
Edge hardening: v1.9.19 duplicate-PID correction, startup nginx -t validation, non-root runtime, fail-fast edge readiness and direct Docker diagnostics are retained.
Backend/data: v1.9.18 Redis authentication/readiness fix and Flyway safety behavior are retained unchanged.
Topology: edge remains loopback-only at 127.0.0.1:4002 and continues to proxy to backend:8080 and web:3000 on the isolated lakhdatar_net.
CI/CD: immutable SHA images, multi-architecture builds, security gates, attestations, provenance verification, public Cloudflare smoke test and manual rollback remain enabled.
Validation performed in packaging sandbox: project baseline validator, JSON/package-lock parsing, YAML parsing, shell syntax, metadata consistency, targeted regression checks and archive integrity. Networked Maven/Docker/npm-registry execution remains environment-dependent and is authoritative in GitHub Actions/Oracle VM.
