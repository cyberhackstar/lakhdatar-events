LAKHDATAR EVENTS v1.9.19 FINAL ENTERPRISE RELEASE MANIFEST
=========================================================
Release: 1.9.19
Base: v1.9.18 Redis-authentication and readiness release.
Primary correction: permanently fixes the production NGINX edge CrashLoop caused by a duplicate PID directive in the official nginx base configuration plus an `nginx -g` PID override.
Edge hardening: rewrites the base NGINX PID path to /tmp/nginx.pid, removes the redundant non-root user directive, validates nginx configuration at container startup, and keeps the edge compatible with read-only runtime storage.
Deployment hardening: edge readiness now fails fast on restarting/exited/dead containers, checks both internal :8080 and host 127.0.0.1:4002 readiness, records port bindings and listener state, and captures direct container logs without Compose argument ambiguity.
Topology: production edge continues to proxy to Docker Compose DNS names `backend:8080` and `web:3000`; host exposure remains loopback-only on 127.0.0.1:4002 for Cloudflare Tunnel.
Security: NGINX edge remains non-root, cap_drop ALL, no-new-privileges, read-only root filesystem, bounded resources, and Alpine security upgrades.
Backend/data: v1.9.18 Redis authentication fix and Flyway safety behavior are retained unchanged.
Frontend: Angular 20.x baseline retained; no framework-major upgrade introduced.
CI/CD: multi-architecture images, Trivy gates, GitHub artifact attestations, provenance verification, immutable SHA deployment, and production dependency audit retained.
